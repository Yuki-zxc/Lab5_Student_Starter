# Перевірки перед здаванням

| Дія | Очікування у завершеній ЛР5 |
|---|---|
| Відкрити сторінку | 1 порція, 2–3 яйця, 1 tbsp, Prepared 0 of 5 |
| Apply 3 | 6–9 яєць, 3 tbsp, поле та output показують 3 |
| Порожнє поле, 0, -1, 11, 2.5 | Помилка, останні прийняті порції збережені |
| Виправити введення | Помилка та aria-invalid очищені |
| +/- до меж | Межі 1–10, крайня кнопка недоступна |
| Позначити eggs і fat, змінити порції кнопками та Apply | Обидві позначки збережені; Prepared 2 of 5 |
| Усі прапорці | All ingredients are ready! |
| Reset двічі на 4 порціях | Позначки очищені, порції залишилися 4 |
| Режим приготування двічі | Збільшення тексту й повернення до початкового вигляду |
| Перезавантаження | Повернення до 1 порції та знятих прапорців |
| 320, 375, 1440 px | Немає горизонтального прокручування та перекриття |
| Tab, Enter, Space | Видимий фокус; кнопки й прапорці працюють |

У стартових файлах перевіряйте спочатку лише функції ЛР4. Решту — після реалізації ЛР5.
Окремо додайте три тести свого індивідуального варіанта. Необов’язкове ШІ-завдання описано в методичці.
