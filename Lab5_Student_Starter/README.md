# Лабораторна 5 — стартові файли для студентів

Повністю розпакуйте архів і відкрийте index.html. Усі шрифти та зображення локальні; сервер і встановлення пакетів не потрібні.

## Що вже працює
Порції 1–10 кнопками +/−, прапорці п’яти інгредієнтів, лічильник Prepared і Reset checks. individual.js містить демонстраційний режим приготування з ЛР4.

## Що потрібно зробити
Це вихідна основа ЛР4 для виконання ЛР5, тому поля Apply, моделі recipe, списку Still to prepare та відсотків тут ще немає. Це завдання студента, а не помилка архіву.

1. Прочитайте docs/Lab_5_Recipe_Calculator_UA_Reviewed.docx.
2. Виконайте крок 1: HTML та CSS. У файлах є TODO.
3. Замініть спільну реалізацію js/script.js узгодженими кроками 2–8 методички. Не додавайте новий код після старого: імена та обробники не повинні дублюватися.
4. Реалізуйте один із 15 варіантів через updateLab5Extra відповідно до методички.
5. Пройдіть перевірки з TEST_CHECKLIST.md і оформіть звіт.

## Якщо ваша ЛР4 уже завершена
Продовжуйте власний проєкт. Цей набір можна використати для відновлення основи. Спершу збережіть резервну копію. Перенесіть власний individual.js разом із його HTML, CSS та підключенням; не замінюйте його демонстрацією режиму приготування. Залежності від quantities, data-min/data-max або старих констант адаптуйте до recipe. Якщо ваш код змінює checked програмно, викликайте updateIngredients().

## Файли
index.html — розмітка; css/style.css — стилі; js/script.js — спільна частина; js/individual.js — приклад ЛР4; assets — зображення та шрифти; docs — актуальна методичка.

Для здавання перейменуйте папку на recipe-page_Surname_Lab5. Методичка містить опорний код спільної частини; повного інтегрованого розв’язку ЛР5 у стартовому script.js немає.
